# acoustic/ (Dev 3)

## What it does
Low-frequency energy detector: for each frame of `acoustic.frame_s` seconds it computes the ratio
between the energy in the `acoustic.band_hz` band and the total energy (STFT with librosa). Consecutive frames above the threshold,
lasting at least `min_event_s` seconds, become a `SensorEvent` of type `acoustic_lowfreq`.
Results are precomputed; the pipeline reads them filtered by `now`.

## Clips
- `clips/manifest.json`: for each clip, the (simulated) hydrophone id, its position and `offset_min` from `scenario.start`.
- `clips/background_noise.wav` and `clips/lowfreq_tone.wav`: SYNTHETIC, generated by `python -m acoustic.make_test_clips`
  (4 kHz, 20 s; white noise vs. a 50 Hz + 100 Hz tone).
- **Real clips:** do not download datasets into the repo. Put the `.wav` files received from the organisers in
  `acoustic/clips/real/` (ignored by git) and add a manifest entry with `"file": "real/<name>.wav"`,
  the sensor position, `offset_min` and `"simulated": false`.

## Consumes
The clips in the manifest, `config.yaml` (`acoustic`, `scenario.start`).

## Produces
`out/acoustic_events.json`: a list of `SensorEvent` (`source="acoustic"`).

## Running it on its own
```bash
python -m acoustic.make_test_clips
python -m acoustic.analyze --out-dir out
python -m pytest acoustic
```
`librosa` is used only in this directory.
