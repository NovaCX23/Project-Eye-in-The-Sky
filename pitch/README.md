# pitch/ (Dev 5)

## What it does
The presentation material, in English.
- `outline.md`: structure of the presentation and the demo beats.
- `jury_questions.md`: likely questions and short answers.
- `metrics.md`: GENERATED by `/eval-report`, held-out seed only. Never edited by hand.

## Consumes
`pitch/metrics.md`, screenshots from the demo.

## Produces
The presentation.

## Running it on its own
```bash
python -m eval.evaluate --seed-set both --run --write-md pitch/metrics.md
```
